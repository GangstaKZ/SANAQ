# SANAQ

Менеджер магазина на Vite + React 18, только JavaScript. Инструкция проекта: `AGENTS-SANAQ.md`.

## Запуск

```sh
npm install
npm run dev
```

Без `.env` работает локальный магазин: 20 начальных товаров, реальные продажи, IndexedDB (Dexie). Начальные данные создаются один раз; продажи изначально отсутствуют. Для сброса удалите IndexedDB `sanaq-local-v1` в инструментах браузера.

```sh
npm run test
npm run build
npm run preview
```

Браузерные проверки: `npm run build`, затем `npm run test:e2e` (Chrome). Playwright сам запускает dev/preview-серверы, если они ещё не запущены. Скриншоты сохраняются в `artifacts/`.

## Supabase

1. Выполните **supabase.sql** в SQL Editor. Это расширенная версия исходного `Supabase-Sanaq.sql`: добавлены исторические цены, атомарная функция продаж, защита от повторного списания и Realtime.
2. Скопируйте `.env.example` в `.env`, заполните URL проекта и публичный anon key.
3. Перезапустите Vite. Для облачного проекта используется отдельная локальная база; демонстрационные локальные данные в Supabase автоматически не загружаются.

Схема использует открытые RLS-политики из задания для одного демонстрационного магазина. Auth-клиент настроен в `src/lib/supabase.js`; вход пользователей и разделение магазинов не входят в эти шесть шагов. Для публичного SaaS нужны Auth и политики по владельцам магазина. Секретный service-role key в браузер не добавлять.

## Возможности

- Каталог: поиск по названию, артикулу и штрих-коду, категории, фильтр остатков, создание, редактирование и удаление через Dialog.
- Excel: скачиваемый шаблон, импорт первого листа, обновление по штрих-коду. Столбцы `name, sku, barcode, quantity, min_stock, buy_price, sell_price, category` или русские названия из формы. Храните штрих-коды как текст для сохранения ведущих нулей. Невалидный импорт откатывается полностью.
- Сканер: камера с разрешением браузера (HTTPS/localhost), ручной ввод, добавление найденного товара в корзину.
- POS: постоянная корзина Zustand; проверка количества и цены; атомарное списание всех позиций, сохранение цены на момент продажи.
- Dashboard: выручка за сегодня и семь календарных дней по локальному времени устройства, стоимость по закупочным ценам, пять товаров с низким остатком, последние позиции продаж, PDF с кириллицей.
- Поставщики: создание и редактирование контактов.
- RU/KZ-переключатель основных подписей интерфейса; названия товаров и служебные сообщения сохраняют исходный язык.
- PWA: оболочка кешируется после первого открытия production-версии, поддерживаются маршруты offline. Для установки используйте меню браузера.

## Offline и синхронизация

Изменения сначала записываются транзакцией в Dexie. В облачном режиме очередь отправляется при восстановлении сети, каждые 30 секунд и после операций; Realtime обновляет каталог и бейдж. Сервер обрабатывает каждую операцию один раз, блокирует остатки во время продажи и предотвращает отрицательный склад. Ошибки и неподтверждённые операции видны в верхней части экрана. Сохранённая offline-продажа до синхронизации ещё не подтверждена сервером.

При конфликте остатков/цен между устройствами очередь останавливается, локальные данные сохраняются, ошибка показывается пользователю. Автоматического разрешения таких конфликтов нет: нужно согласовать данные на сервере и повторить отправку. Редактирование остатков также проверяет исходный остаток, чтобы не затереть параллельную продажу. Открытая схема предназначена для портфолио, не для многопользовательского промышленного учёта.

## Публикация

Vercel: Build `npm run build`, Output `dist`, переменные из `.env.example`. `vercel.json` обеспечивает fallback для React Router. Камеру и Realtime нужно проверить на вашем устройстве и подключённом Supabase: без проекта и разрешения камеры эти интеграции нельзя проверить полностью.

## Зависимости

SheetJS установлен из официального CDN (0.20.3), Tailwind CSS — v4. Проверка npm audit оставляет две moderate-записи для React Router v6, закреплённого инструкцией проекта; исправление требует перехода на v7. Приложение использует только заданные локальные маршруты и не использует SSR.
